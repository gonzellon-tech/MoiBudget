# Как получить APK через облачную сборку GitHub

Этот проект содержит GitHub Actions workflow, который собирает `app-debug.apk` в облаке GitHub.

## Что понадобится
- Аккаунт GitHub.
- Создать новый пустой репозиторий на GitHub.

## Шаги
1. Распакуйте `MoiBudgetAndroid_project.zip` на компьютере.
2. Создайте на GitHub новый репозиторий, например `MoiBudgetAndroid`.
3. Загрузите в репозиторий **все файлы и папки проекта**, включая скрытую папку `.github`.
   Важно: в корне репозитория должны лежать `settings.gradle.kts`, `build.gradle.kts`, папка `app` и папка `.github`.
4. Откройте вкладку **Actions** в репозитории.
5. Выберите workflow **Build Android APK** и нажмите **Run workflow** (или дождитесь сборки после загрузки файлов).
6. После завершения откройте успешный запуск workflow, внизу страницы найдите **Artifacts** и скачайте `MoiBudget-debug-apk`.
7. Распакуйте скачанный архив. Внутри будет `app-debug.apk`. Перенесите его на Android-телефон и откройте для установки.

## Примечание
- Это debug APK для личной установки, не подписанный release APK для Google Play.
- Для установки может потребоваться разрешить установку приложений из выбранного файлового менеджера.
- Проект пока не проходил реальную сборку в этой среде. Если облачная сборка покажет ошибку, пришлите текст ошибки или скриншот вкладки Actions — по нему можно исправить проект.
